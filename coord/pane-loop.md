# Whole-app completion and test-loop handoff

- **Scope correction:** the Astro app is the entire repository and local source/data tree. `waiwai1/` is an integral part: its capture, logger, CSI analysis/calibration, live-view, I/Q experiments, firmware, Context Engine, fixtures and tests are used by the app workflow. Do not describe it as another product.
- **App map:** React pages/components in `frontend/`; FastAPI routes and services in `backend/`; typed contracts/models/SQLite/Alembic in `backend/schemas`, `backend/models`, `migrations`; CSI ingest/features/baselines/fusion in `csi_core/`; team estimator adapters in `plugins/`; operator CLI in `tools/cli.py`; setup/ops in `scripts/` and `tools/ops/`; survey/guidance seeds in `seeds/`; hardware and analysis scripts/data under `waiwai1/` and `features script/waiwai1 exported/`.
- **How script data reaches app:** raw sessions normalize via `plugins/team_capture.py` to the csi_core capture-folder format, then `backend/services/ingestion.py` and `services/pipeline.py` process/save them. `plugins/team_*` call vendored copies under `plugins/vendor/waiwai1.exportused/`. Precomputed estimates have a second path through `services/injection.py`, `/api/v1/ingest/estimates`, jobs and live/replay SSE. BRIDGE-1 is still needed to make script output reliable end to end. The Context Engine is in `waiwai1/engine/api.py`; required backend delegation to `run()` is currently absent.
- **Critical constraints:** never change `engine/`, `context-v2.md`, evaluator rules or fixed constants; backend must call `engine.api.run()`. Fix non-engine code only after a failing regression test, max 3 attempts per bug, one commit per fix. Do not alter raw captures. Keep PHQ-9/severe-symptom safety first, preserve privacy/isolation and provenance.
- **Run loop:** from repo root, `python loop/run_loop.py --smoke`; full `python loop/run_loop.py --iterations 20 --budget-min 60`. Project dependencies must be installed. Smoke/full writes `loop/reports/`; confirmed failures go to `loop/BUGS.md`. Frontend checks: `cd frontend && npm test && npm run build`; Python gate: `pytest && ruff check .`.
